# common

负责全项目通用且无业务语义的基础能力：`Status`、`Slice`、二进制编解码、
CRC32、日志器和任务队列。

- 上游调用方：`net`、`rpc`、`storage`、`raft`、`server`、`client`。
- 下游依赖：C++ 标准库和操作系统基础 API，不依赖其他业务模块。
- 修改注意：保持低层接口稳定；涉及并发时明确线程安全边界，避免把上层策略放进本模块。

## 当前接口约定

- `Slice` 是非拥有视图，被引用数据必须在所有 `Slice` 副本使用期间保持有效。
- `Status` 是成功或失败的统一返回值；成功状态不携带消息。
- 持久化定长整数使用小端，网络定长整数使用大端。
- 长度前缀字符串使用 4 字节小端长度，读取时推进输入 `Slice` 且不复制载荷。
- `Crc32` 使用标准 CRC-32/ISO-HDLC 参数，结果与 zlib 和以太网 CRC32 一致。
- `Logger` 同步串行化完整日志行，包含毫秒时间、级别、节点、线程和调用位置；
  默认输出级别为 `INFO`。
- `MpscQueue` 支持多个生产者，但消费者只能有一个；`PopBatch` 会清空输出参数并
  取出等待时已到达的全部元素。
